# Glosario breve

- **WSL2:** entorno de Linux integrado en Windows mediante virtualización.
- **Interfaz virtual:** interfaz de red creada para conectar componentes virtualizados.
- **TCP connect scan (`-sT`):** Nmap intenta completar una conexión TCP.
- **`-Pn`:** omite el descubrimiento de host y trata el objetivo como activo.
- **`-n`:** evita resolución DNS durante el escaneo.
- **`-sV`:** intenta identificar el servicio que escucha en un puerto.
- **`open`:** existe un servicio accesible en el puerto TCP observado.
- **`closed`:** el host respondió, pero no hay servicio escuchando en ese puerto.
- **`filtered`:** no hay evidencia suficiente para decidir abierto/cerrado; puede haber filtrado o falta de respuesta.
- **Endpoint Mapper / RPC-EPMAP:** componente RPC de Windows que ayuda a los clientes a localizar endpoints RPC.
- **`ActiveStore`:** vista de la política de firewall activa en Windows.
- **Evidencia vs. hipótesis:** una observación directa no es lo mismo que una explicación causal de esa observación.
